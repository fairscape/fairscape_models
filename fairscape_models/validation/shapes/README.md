# Bundled SHACL shapes

`fairscape-shapes.ttl` is a copy of the published FAIRSCAPE profile shapes,
`https://fairscape.github.io/profile/0.2/fairscape-shapes.ttl`. The source of
truth is the profile repository (`profile/0.2/fairscape-shapes.ttl`). Refresh the
copy from there, and bump `SHAPES_VERSION` in `../shacl.py` when the profile
version changes.
